# StageFund Development TODO

## 1. Document Overview

This document serves as the master execution checklist for the StageFund project.

Its purpose is to convert the approved Development Roadmap into actionable implementation tasks.

Each task shall be completed sequentially, verified, and approved before proceeding to the next task.

This document is intended for developers, Team Leaders, and AI-assisted development tools.

The TODO document complements all approved project documentation and shall be treated as the implementation checklist throughout the project lifecycle.

---------------------------------------------------------------------

## 2. General Development Rules

The following rules apply to every implementation task.

---

## General Rules

- Follow all approved documentation.
- Follow the approved Development Roadmap.
- Follow the approved Project Structure.
- Complete tasks sequentially.
- Verify every completed task.
- Obtain Team Leader approval before major phase transitions.

---

## AI Rules

AI shall:

- Never assume missing requirements.
- Never modify approved documentation.
- Never change architecture.
- Never change database design.
- Never change API design.
- Never create unnecessary files.
- Stop and request clarification whenever information is incomplete.

---

## Quality Rules

- Reuse existing code.
- Avoid duplicate implementations.
- Keep modules independent.
- Keep components reusable.
- Maintain architecture consistency.
